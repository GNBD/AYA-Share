# AYA Share


별도의 복잡한 설정 없이, 동일한 네트워크 환경이라면 파일을 주고받을 수 있습니다.

모바일은 클라이언트가 필요없습니다.

## ✨ 주요 기능 (Features)
* **간편한 공유:** QR 코드 스캔 한 번으로 모바일과 PC 연결.
* **미리보기:** 이미지, 텍스트, 비디오 등 다양한 형식을 브라우저에서 즉시 확인.

## 🚀 시작하기 (How to Use)
1. **프로그램 실행:** 프로그램을 실행합니다.
2. **접속:** 화면에 생성된 QR 코드를 모바일 기기로 스캔합니다.
3. **공유:** PC클라이언트 창이나 모바일 브라우저 에서 파일을 선택하여 원하는 파일을 공유할수있습니다.

## ⚠️ 주의 사항 (Known Issues)
* **고용량 파일:** 현재 대용량 파일 전송이 불안정할 수 있습니다.
* **네트워크 환경:** 반드시 PC와 모바일 기기가 동일한 라우터 네트워크에 연결되어 있어야 합니다. (DMZ를 사용하는 경우 주소가 외부로 유출되지않게 주의하십시오)
* **면책조항:** 사용자는 본 소프트웨어 사용으로 인해 발생하는 모든 책임을 스스로 감수해야 하며, 제작자는 이에 대해 어떠한 책임도 지지 않습니다. 중요 데이터는 반드시 별도 백업하십시오
